To keep access to BT devices you have to enable Web Bluetooth new permissions backend and relaunch the application.
Copy this into your browser chrome://flags/#web-bluetooth-new-permissions-backend
This Doora application connects to Shelly switch device with enabled Bluetooth and calls toggle action.

Password protection is set by Shelly Settings/Authorization (currently visible only in Shelly web administration).
